01 — About

백엔드 엔지니어입니다.
눈에 보이지 않는 걸 만듭니다.

서버에서 돌아가는 프로그램과, 그와 연결되는 프로그램을 만듭니다.

기술 스택

TypeScript 기반 Node.js로 개발하며 서버 프레임워크는 Nest.js를 주로 씁니다. MySQL 계열 DB를 직접 쿼리와 TypeORM으로 다루고, Aurora MySQL 마이그레이션과 운영, Redis·DynamoDB 캐싱, RabbitMQ와 SQS를 조합한 태스크 분산을 프로덕션에서 운영했습니다.

경험

MAU 75만 백엔드 서버부터 일 500만 건 규모의 크롤링 시스템, 4대 규모의 데이터베이스 클러스터, 클라우드와 온프레미스에 걸친 인프라와 사내 네트워크까지 다뤘습니다. 약 9년의 개발 경험과 5년 3개월의 현업 경력 동안 백엔드와 연관된 프론트, 인프라, CI/CD를 개발했고 여러 프로젝트의 아키텍처를 설계했습니다.

클라우드 & 운영

AWS를 주력으로 GCP, 네이버 클라우드를 비용과 필요에 맞춰 혼합 운영했습니다. GitHub Actions CI/CD와 AWS SDK 배포 로직, Sentry·Grafana 기반 모니터링을 Slack과 연동해 운영했습니다.

협업

동료는 물론 베스핀글로벌 같은 MSP, 스마트로·포트원·네이버 쇼핑 같은 파트너사, 입점 고객사, 공공기관까지 다양한 외부 협업과 API 연동을 경험했습니다.
